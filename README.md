# Filvero website

Static landing page for Cloudflare Pages. No build step is required.

## Local preview

Open `index.html` in a browser, or use any static-file server.

## Cloudflare Pages

Set the production branch to `main`. Leave the build command and output directory empty, then deploy this `website` directory as the project root.

Before public launch, replace the `Download coming soon` link in `index.html` with the URL of the official Filvero GitHub Release.
